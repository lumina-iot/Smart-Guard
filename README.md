
# 🛡️ Smart-Guard: IoT-Based Smart Temperature and Security System

## 📌 Project Description

**Smart-Guard** is an IoT-based smart monitoring system developed using the ESP32 microcontroller and simulated on the Wokwi platform. It combines temperature monitoring and security detection to help users monitor environmental conditions and potential security threats.

The system connects to the **Blynk IoT mobile application** through Wi-Fi to send notifications when configured temperature thresholds are exceeded or security events are detected. This enables users to monitor their surroundings and receive alerts remotely through their smartphones.

The project demonstrates how IoT technology can improve home monitoring by combining sensor-based detection, wireless communication, and mobile notifications in a single system.

## 🎯 Objectives

- Monitor temperature conditions in real time.
- Detect potential security events using connected sensors.
- Send alerts to the Blynk IoT mobile application.
- Enable wireless monitoring through Wi-Fi.
- Simulate and test the system using Wokwi.
- Demonstrate an affordable IoT-based smart monitoring solution.

## ⚙️ Technologies Used

- **Simulation Platform:** Wokwi
- **Microcontroller:** ESP32
- **Programming Language:** Arduino C/C++
- **Mobile Application:** Blynk IoT
- **Communication:** Wi-Fi
- **Sensors:** Temperature and security sensors used in the circuit

## ✨ Key Features

- 🌡️ Temperature monitoring.

## 🔄 How It Works

1. The temperature sensor measures the surrounding temperature.
2. The security sensor monitors for events such as motion or unauthorized activity, depending on the sensor used.
3. The ESP32 reads and processes the sensor data.
4. The ESP32 connects to Wi-Fi and communicates with the Blynk IoT platform.
5. When a configured alert condition occurs, the system sends a notification to the Blynk mobile application.
6. The user can view the received alerts on their smartphone.
